# Phishing Email Analysis

**Cyber Security Internship – Task 2**

## Project Overview

This project focuses on identifying and analyzing phishing characteristics in suspicious email samples.

## Objectives

- Analyze suspicious email sender information.
- Understand email header authentication.
- Examine suspicious URLs.
- Identify social engineering techniques.
- Document phishing indicators and security recommendations.

## Tools Used

- Gmail – Original email and header extraction
- Google Admin Toolbox – Messageheader analysis
- Text Editor – Email inspection
- GitHub – Project documentation

## Methodology

1. Collected a simulated phishing email sample.
2. Examined sender details.
3. Reviewed available email header evidence.
4. Inspected suspicious URL characteristics.
5. Identified social engineering indicators.
6. Prepared an investigation report with screenshots.

## Key Findings

- Urgent and threatening language.
- Unverified sender identity.
- Suspicious account verification request.
- HTTP URL in the simulated sample.
- Social engineering techniques.

## Project Structure

- `Sample-Email/` – Email sample
- `Header-Analysis/` – Sender and header observations
- `URL-Analysis/` – URL investigation
- `Screenshots/` – Evidence screenshots
- `Report/` – Final PDF report

## Conclusion

This project demonstrates the basic methodology of phishing email investigation, email-header analysis, URL inspection, and cybersecurity awareness.

## Disclaimer

Educational project using a simulated phishing sample. No real users or systems were targeted.
